# Background streaming
- **A background game starts once and keeps its controller.** Nucleus Co-op's auto-play could start a game a second time while the first start was still running, which killed the first one. That looked like the game refusing Rubylight's input hooks, so after a few launches the game ran without them and the controller only worked while its window had the focus. Rubylight now presses Play itself, once, after the profile is loaded, and forgets what it learned from those false refusals, so those games get their hooks back. A game that really refuses the hooks learns that again, with one failed launch per way of injecting. Handlers with setup steps of their own keep Nucleus Co-op's auto-play, because Nucleus Co-op shows no Play for them. Measured with Assassin's Creed Black Flag Resynced on the RX 7900 XT: 4 of 6 starts ran before, 12 of 12 now, each launching once with the hooks loaded. With another window in front, the client's D-pad moved the game's menu.
