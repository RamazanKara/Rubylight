# Quick Suspend
- **Quick Suspend.** Pause the running game from Nightjar's stream menu or the console's Home page and resume it later, from the same device or another one. Turn it on with the new Quick Suspend setting (App behavior, off by default). Rubylight writes down what it paused before it pauses anything, so the game is resumed if Rubylight stops, crashes, restarts or the PC reboots while it is paused, and ending the session, closing the game or starting a stream of it resumes it first. It refuses with the reason, and pauses nothing, for a game with anti-cheat, a protected or system process, a launcher, a co-op or guest session, or anything outside the game's own processes; if any part of a pause fails, what was paused is resumed.
