# Switch 2 Pro Controller and motion server
- **Switch 2 Pro Controller.** With usbip-win2 installed, a Nightjar client's Switch 2 Pro Controller appears on the PC as a Switch 2 Pro Controller, which SDL games and Steam recognise: the C button, both grip buttons, both sticks, gyro and accelerometer, battery and rumble. Other controllers keep their pad. **Switch 2 Pro (USB/IP)** under Controller type gives every controller one. Without usbip-win2 the controller arrives as a Switch Pro and the console says why.
- **Motion server for emulators** (off by default). Turn on **Motion server for emulators (DSU)** under Controllers, and Cemu, Dolphin, Citra and other emulators read each streamed controller's gyroscope, accelerometer, buttons and touch from UDP port 26760. It listens on every network interface without a password; the Windows Firewall keeps other devices out unless you allow the port.
