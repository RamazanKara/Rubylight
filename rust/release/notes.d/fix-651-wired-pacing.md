# Wired slower-link pacing handoff
- **Wired streams with sustained packet loss now probe back up (#168).** When a wired H.264, HEVC, or AV1 stream with Packet pacing on `auto` and a client reporting FEC status hits sustained frame loss (or starts from a remembered lossy route), the host hands pacing over to adaptive packet pacing starting at twice the bitrate instead of staying locked at the Wi-Fi pacing rate for the rest of the stream, probing back up as the link stays clean (capped below the rate that failed on mid-stream handoff, locking at the last clean rate on probe loss, and holding the safe rate when FEC is below 10%) without reducing bitrate. Clean wired streams, temporary start-up or send-buffer latches, PyroWave, fixed or disabled pacing, and clients without FEC status keep their existing behavior.
