# Full chroma on HEVC at large sizes
- **Full chroma on HEVC is no longer refused at 2560x1600 and other large sizes.** Full chroma doubles the coded height, so 2560x1600 is coded as 2560x3200. From about 6.2 million coded pixels (2560x1210, 1920x1618 and up), the host sends each HEVC frame as four slices. The check the host runs before a full-chroma stream counted each slice as a frame and refused the stream with "packed encoder failed to return frame 2". The check now counts whole frames. AV1 wasn't affected. Fixed from the reporter's log and the code; we haven't streamed it on an RX 9070.
