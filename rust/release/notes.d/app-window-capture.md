# One app's window
- **Stream one app's window instead of a display.** Set **What to stream** to **The app's window** for an app in **Games**, for one device in its **Per device** panel, or for every app under **Picture → Capture**. The host finds the window among the programs the app started, or by a program name and title you set, keeps its shape with black bars, and maps mouse, touch and pen onto it. Resizing, switching between windowed, borderless and fullscreen, DPI changes and moving the window to another monitor are followed. While the window is minimised, before it opens and after it closes, the stream shows the display and the device says why; **When the window closes** can end the stream instead.
