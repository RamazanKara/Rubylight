# AMF bitrate ceiling
- **A bitrate above what the Radeon encoder takes no longer refuses the stream.** A device that asked for more than the AMD driver's encoder accepts at that size and frame rate (Nightjar can ask for up to 2 Gbps, left over from PyroWave) got "AMF error AMF_OUT_OF_RANGE" at the start, for Full chroma AV1 already when connecting. The encoder now runs at the driver's own ceiling, reads it from the driver, and the stream's warnings and the host log say which rate it runs at. A peak bitrate ratio set in the config is held to the driver's range the same way. This applies to H.264, HEVC and AV1, and to bitrate changes during a stream (nightjar#80).
