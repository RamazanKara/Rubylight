# On by default
- **Full chroma for Nightjar is on by default.** Nightjar's **Sharper colored text** now works without a second switch on the PC. The host only offers full chroma; a stream uses it only when its device asks, so other devices and stock Moonlight are unaffected. A PC where you turned it off keeps it off.
- **Hardware metrics are on by default.** A paired device's overlay can show the PC's CPU and GPU readings during its stream. The host reads them only while a device asks for them. A PC where you turned it off keeps it off.
