# Rubylight 7.0 console
- **A new look for the console.** The web console is redrawn for 7.0 in a dark and a light theme that follow Windows or your choice: a navigation rail, a command bar with search and a live badge while a device streams, and calmer panels, forms and tables. Every page and setting is where it was.
- **Live stage on Home and Sessions.** While a device streams, the top of Home shows what plays and on which device, the stream's health in one word and one sentence, frame rate, bitrate and host frame time over the last two minutes, and where a new picture's time goes on this PC (capture, convert, encode, pace and send). Stream details, Copy diagnostics, Quit game and each device's Disconnect sit right below. The figures are the ones the host measures; nothing is estimated.
- **Guided pairing.** Pairing shows three steps and what to do now: the QR code on its own paper with its time running out, the access choice as cards (Play games, Watch only, Everything), the PIN field as soon as a device asks, and the device's card once it is paired.
- **Command palette.** `Ctrl+K` (`⌘K` on a Mac) now also lists host actions (pair a device, sync games, disconnect every stream, switch the theme, restart Rubylight) and diagnostics (Troubleshoot, Sessions, Logs, support bundle), next to pages, games with their covers, devices with their state, and settings.
- **A studio header on each game's page.** The game's cover, lit from behind by its own art, with its launcher, whether it runs, the stream profile it carries, Launch and Edit cover.
- **Who decides a stream setting, at a glance.** On a game's page under Per device, and on a device's page under Stream settings, each setting is a card that shows which layer decides it (this game on this device, the game, the device, then the host), every layer's value, and a Reset to inherited button. Resolution, refresh rate, display HDR, virtual display, bitrate limit, error correction, HEVC and AV1 support, full chroma, the frame limiter, audio capture, virtual speakers, microphone, 7.1.4 surround, mouse mode and controller support can now be set per device, and per game on one device, from the console (#140).
- **A map of your displays.** Troubleshoot and each device's Display overrides draw the connected displays where Windows arranges them, with resolution, refresh rate, scale, HDR, the primary one, virtual displays and the display a device streams. The map only shows; arranging displays stays in Windows.
