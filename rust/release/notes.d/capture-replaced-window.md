# Background streaming
- **A game that replaces its window as the stream starts no longer ends the stream.** When a game swapped its splash window for its main window just as the capture opened, the capture waited five seconds for a frame the old window would never send, and the stream ended with "WGC helper did not produce a first frame". It now gives up on a closed or hidden window at once and opens the new one, and a capture that did wait the whole five seconds gets another try. With a test game whose window is hidden at that exact moment, the stream started about 2 s after the client connected, and about 5.5 s with only the extra try.
