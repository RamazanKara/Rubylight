# Virtual mouse and touchpad
- **A mouse games read like a real one.** For games that ignore Windows input injection, the PC's mouse can be a virtual USB mouse polled every millisecond, with fine wheel steps and horizontal scroll, using the optional USB audio and haptics driver. Choose it in **All settings › Sound & controls › Mouse input method** (`mouse_mode`): Injection (the default), Virtual mouse, or Automatic (the virtual mouse when the driver is there), also per game and per device. Without the driver, mouse input is injected as before, and the stream says why when Virtual mouse was chosen.
- **Touchpad gestures from devices.** A tablet's keyboard-cover touchpad or a laptop's touchpad in Nightjar reaches Windows as a precision touchpad, so two-finger scroll, three- and four-finger gestures and Windows' touchpad settings work (`native_touchpad`, on by default, with the same driver).
- `input_latency_probe` shows whether a game sees the mouse as injected and how long a move takes to reach it ([Virtual mouse and touchpad](../docs/virtual-mouse.md)).
