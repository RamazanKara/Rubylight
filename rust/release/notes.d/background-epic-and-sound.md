# Background streams
- **Background streams keep the game off the PC's speakers.** A device's "play audio on the PC" no longer brings a background stream's game sound to the PC; it still applies to that device's normal streams. Without a virtual playback device the game stays audible on the PC and the stream warns.
- **Epic games in background streams.** A game the Epic Games Launcher installed now starts with the arguments that say which game it is, so it shouldn't restart on the PC's monitor, and if its instance still exits at once the stream says that may be why.
