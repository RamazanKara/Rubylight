# AV1 intra refresh
- **AV1 no longer uses intra refresh.** When a client asks for intra refresh on AV1, the host now leaves it off and recovers from a lost frame with an invalidated reference frame, as for a client that never asked. Measured on the RX 7900 XT (driver 32.0.32015.7029, AV1 1440p120 at 50 Mbps, one lost frame): with refresh, the driver turned off long-term references, so recovery took a 101 KB keyframe and inter frames averaged 51 KB; without it, recovery took a 48 KB invalidated frame and inter frames averaged 34 KB. Refresh alone never recovered. H.264 and HEVC intra refresh are unchanged.
