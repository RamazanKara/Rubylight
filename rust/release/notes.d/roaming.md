- **Client roaming (Experimental).** A device whose network address changes mid-stream, such as a phone moving from Wi-Fi to mobile data, can keep its stream instead of reconnecting. The device proves its new address with the stream key before the host sends anything there; the host then moves control, video and audio to it, sends a keyframe, starts pacing the new path from scratch and drops what still arrives from the old address. A device can roam again, or back to where it started. Only devices that support it (Nightjar) use it; other Moonlight clients stream exactly as before. `client_roaming` (on by default) turns it off.
