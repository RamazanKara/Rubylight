# Webhooks and QR pairing
- **Webhooks.** The console's new Webhooks page (Settings, Network) sends signed JSON events to your URLs when devices pair or are removed, apps start and stop, and streams begin and end. Each hook has its own secret, shown once, and a Send test button; deliveries are retried, never hold up a stream, and each hook shows its last result. See docs/webhooks.md for verifying signatures and the 5-minute replay window.
- Experimental: **Pair with a QR code.** With Pair with a QR code on in Settings, the Devices page shows a QR code to pair Nightjar without typing a PIN: Nightjar on Android scans it with Scan QR code in Add PC, and Nightjar on Windows and Linux pastes the link from Copy pairing link. It holds a one-time PIN that works once and expires after 3 minutes, and Nightjar refuses to pair when the PC's certificate is not the one the code names.
