# Service file
- **The service file stays the same across updates.** `butterpollo-service.exe` now changes only when its own code does, so after an update antivirus programs see a file they already know instead of a new one. The service starts and watches the host, watches the display driver and rolls back interrupted updates as before, and starts no process on a timer: it asks the host about the driver only when the device appears or before a repair, and the Nucleus Co-op restore runs as the host starts and as you sign in.
- Every Rubylight executable now names its company, copyright and original file name in its file properties.
