# Play in a TV browser
- **Play from a TV, console or car browser, with no app.** With the WebRTC server on, open `https://<PC address>:47991/play` on the local network or Tailscale, pair once with the PIN the page shows (enter it on **Devices**), then pick a game with the remote, the arrow keys or a controller and play full screen. Hold Back or Select for a second for Disconnect and Quit game. The browser warns about the PC's certificate once. The page answers no address outside the local network and Tailscale, refuses connections from the PC's router, and pairs only with the PIN you type in the console, which shows the address each request came from. Measured in Chrome and Edge on the RX 7900 XT PC (1080p60 over loopback): H.264 and AV1 at 60 fps with no frames dropped, and 9.2 to 9.9 ms from a frame's arrival to its display, as on the console's Stream page.
