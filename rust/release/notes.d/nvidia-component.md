# NVIDIA components
- **RTX HDR and RTX Video enhancement come to the signed host.** On a PC with an NVIDIA graphics card, **Settings → Picture → Integrations → NVIDIA components → Download** fetches the NVIDIA files they need, about 17 MB from this release, and checks every file; **Remove** deletes them. There is no separate NVIDIA build any more: the RTX settings, the app editor and Nightjar offer the enhancements once the NVIDIA components are installed and the graphics card and driver support them. Settings found by search say what they need: an NVIDIA graphics card or the NVIDIA components.
- **Hosts of the NVIDIA build move to the signed host.** Their next update installs the signed host and removes the NVIDIA build's files; RTX settings and per-app values stay. Download the NVIDIA components once on the console to use RTX HDR or RTX Video enhancement again.
- **A too-old NVIDIA driver is named.** Where RTX HDR or RTX Video enhancement needs a newer NVIDIA driver, the console says which version.
- **RTX HDR shapes highlights up to 2000 nits itself.** NVIDIA's model now gets the display's peak brightness up to 2000 nits, where it used to get at most 1000 and the host scaled the picture up from there. A peak set above 2000 nits is held at 2000.
