# Library sync ownership
- **The library sync never changes an app you made.** Steam, launcher and Playnite syncs rename, update or remove only the apps they added themselves. Apps you made, edited or brought over from another host keep their name, command and settings, also when the game is uninstalled, left out or no longer among your recent games. The sync only fills in a missing cover and never adds a second app for a game you already have.
- **Editing a synced game makes it yours.** Saving a synced game in the console keeps it in your list for good; the editor says so before you save.
- **Deleted games stay deleted, Steam games too.** A game you delete from the library isn't added back by any sync. Adding it again with Add games brings it back.
