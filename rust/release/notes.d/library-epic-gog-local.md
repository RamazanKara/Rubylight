# Game library scanning
- **Game folders in Add games.** Choose folders that hold one game per subfolder (Settings › Library › Game folders, such as `D:\Games`), and Add games lists each subfolder with the program that starts it. Installers, uninstallers, redistributables, crash reporters, updaters and anti-cheat services are skipped, programs more than two folders down are not read, hidden and system folders such as `$RECYCLE.BIN` aren't games, and you can leave folders out by name or path. A folder a launcher already lists shows up once, under that launcher. The host runs as a service and can't see mapped network drives: enter a network folder by its `\\server\share` path.
- **Epic Games and GOG scans can be turned off** in Settings › Library › Other launchers. Both stay on by default. The scan skips a launcher you turn off, or a game folder you remove or leave out, and doesn't report games already added from it to Nightjar as uninstalled. Saving a Library setting starts a new scan.
- **No duplicates from Playnite or Steam.** A scanned game Playnite already added from the same launcher, or a game folder Steam, Playnite or another app already starts, shows as already added. The same title from two launchers still counts as two games.
- **Scan problems are logged.** A launcher whose scan fails, or a game folder that's missing, is marked incomplete in Add games and now also written to the host log. The other launchers' games are still listed.
- Experimental: GOG games installed with only a registry record (older offline installers, no `goggame-<id>.info`) are listed too, and start with their own program.
