# Microphone level
- **The streamed microphone no longer clips into noise.** Windows' recording slider for Microphone (Steam Streaming Microphone) runs up to +30 dB, with 0 dB at 54: at 100, or wherever a voice app's automatic gain pushed it, the client's voice reached apps 30 dB too loud and turned into distorted noise. While a client's microphone plays, Rubylight now keeps that slider at 0 dB or lower, checking again every second, so the level set in Nightjar is the level apps hear. A lower level stays as you set it. Measured through Steam Streaming Microphone on the RX 7900 XT PC with the slider at 100: 43% of speech samples over full scale before, none after, tones back at 0.0 dB from +30 dB.
- The host log now names Steam Streaming Microphone's playback and recording formats each time a client's microphone starts, and Rubylight reads the playback format back after setting it, so a format Windows doesn't keep shows up as a warning instead of distorted sound.
