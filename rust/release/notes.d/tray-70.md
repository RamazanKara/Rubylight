# Tray 7.0
- **The tray says what Rubylight is doing.** The icon carries a status dot in the 7.0 colours: green while a client streams, amber while the game waits for its client to come back, coral when a game closed right after it started. The plain ruby icon still means Rubylight is ready. A dark and a white ring keep the dot readable on light and dark taskbars, and the dot is redrawn at the right size when Explorer restarts.
- **A status-first tray menu.** Its first line says what is happening ("Streaming Portal 2", "Ready", "Needs attention: ..."), followed by Open Rubylight, Pair a device, a new Enter PIN entry, Stop streams and restore displays, Quit the running app, and Restart Rubylight. A game that fails to start now says so in plain words: "Portal 2 closed right after it started (exit code 1). Click to end the stream."
