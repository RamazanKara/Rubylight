- **Dolby Vision (Experimental).** HEVC HDR streams offer Dolby Vision profile 8.1 to clients that ask for it: each frame ends with a Dolby Vision RPU built from the same per-frame brightness statistics as HDR10+, over the stream's HDR10 picture, so devices without Dolby Vision and stock Moonlight get the HDR10 stream they always did. Packed 4:4:4 streams carry HDR10 and HDR10+ instead, and the web UI says why. `hdr_dolby_vision` (on by default) turns it off.
