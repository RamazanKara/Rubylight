- **Running setup again after a failed first install.** When a first installation failed after importing Vibepollo's or Apollo's settings, setup now removes that import again, so the next run imports them instead of refusing because Rubylight "already has settings".
- **Uninstall reports what it could not remove.** When removing the Rubylight display driver or the virtual drivers you chose fails, the uninstaller now says so in its final dialog instead of only in its log. A factory reset that cannot delete every file (one held open by an indexer or antivirus) lists what is left and warns that credentials or paired devices may remain on the PC.
