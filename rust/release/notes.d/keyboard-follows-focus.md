- **Keyboard follows text fields (Experimental).** When a client asks for it and the device has the Keyboard permission, the host watches the focused control with UI Automation and tells the client when a text field gets or loses the focus, with its kind (text, number, password and so on; the text box of a number box counts as a number), so Nightjar opens and closes the device's keyboard by itself. Turn it off with `keyboard_follows_focus = false`. Sending the text around the cursor for the keyboard's suggestions is off by default (`text_input_surrounding_text`) and never covers password fields.
- **Keyboard layout (Experimental).** Nightjar reports its keyboard layout, and with `always_send_scancodes` the host turns keys a client does not normalize into scan codes from that layout's file, without loading the layout into Windows or touching the user's input languages. `keyboard_layout` picks the layout: `client` (default) for the reported one, `us`, or a Windows layout id such as `00000407` for a stock Moonlight client, which reports none.
