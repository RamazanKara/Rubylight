## en
- The stream menu is a grid of tiles, the same on Android and desktop, with Return to stream and Disconnect under it; rarely used items moved to More.
- While it is open, Y opens the keyboard, X the controller mouse, RB the overlay and LB your shortcuts.
- Your shortcuts are tiles in the menu, beside Task Manager, Alt+Tab, Alt+F4, Start menu and Show desktop, and Add shortcut saves one from the stream.
- On Android the menu is a panel beside the stream instead of a sheet across the screen; only its grid scrolls, so Return to stream and the ways out stay in view.
- The menu's header names the game and the stream's mode, such as 1440p · 144 FPS · HEVC HDR.
- Desktop's menu now offers Close game, Quit game or End host session under the grid, each asking first.
- A new Stream menu group in Settings → Controls holds how the menu opens and your shortcuts; on Android it adds an optional floating menu button you can drag anywhere.
