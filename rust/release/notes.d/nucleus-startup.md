# Nucleus Co-op
- A background stream through Nucleus Co-op no longer hangs at its start when Nucleus Co-op would ask something first ([#59](https://github.com/RamazanKara/Rubylight/issues/59)). For the session, Rubylight turns off its install-folder check (on Windows 11 it warns about a Documents folder in OneDrive on every start), its reminder of the End key, and its favourites-only and game-type list filters, which could hide the game. Your own choices come back when the session ends, also after a host crash.
- A Nucleus Co-op Settings.ini with keys missing, such as the short one earlier Rubylight versions wrote when the file was gone, is completed from Nucleus Co-op's own defaults instead of stopping Nucleus Co-op with a message nobody sees. Settings with letters such as ü no longer stop every background stream.
- When Nucleus Co-op still doesn't start the game, the stream says why: the message it shows on the PC's screen, that it shows no profile Rubylight, or that it showed no window, with the error it logged if there is one.
