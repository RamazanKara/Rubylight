- **Couch menu (Experimental).** Hold L3+R3 for a second, press Ctrl+Alt+Backspace, or hold the top-left corner by touch, pen or mouse to open a host menu drawn into the stream, so any Moonlight client can use it with no client changes. It offers Back to game, Disconnect (the game keeps running), End session and Close game, with the same permission checks as the native API; End and Close ask you to press again within 5 s. The game gets no input while the menu is open and every held key and button is released when it opens.
- Nightjar and other native clients can open and close it with `POST /api/native/v1/session/couch-menu` when the host lists `session.couch_menu`. Turn it off with `couch_menu = false`; the chords, holds and ways to open it are in the config (`couch_menu_*`). Input-only sessions and the read-back encode path (`wgc_direct_encoder_input = false`) refuse it with a message in the log.
- While the menu is closed the stream does no extra work per frame beyond one atomic read.
