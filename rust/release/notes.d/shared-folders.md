# Shared folders
- **Shared folders (Experimental).** Paired devices can browse folders of the PC, download files from them and, with a write grant, upload to them over the streaming HTTPS port. `shared_folders` names the folders (a JSON list of id, name and path on a drive of this PC; no network shares), and **Devices** shares each with a device to read, or to read and write; Full control and the file transfer permissions don't grant it. Files are read and written as the signed-in Windows user, only inside each folder: links and junctions are neither listed nor followed. Uploads follow file transfer's rules: its size limit and speed while streaming, one upload per device, a taken name numbered, a partial upload never left under the file's name. Taking a folder away from a device ends its running transfers. Nightjar's desktop app has a browser for them on the PC's details page. Stock Moonlight clients are unaffected.
