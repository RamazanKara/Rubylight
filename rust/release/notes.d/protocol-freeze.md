# 3.0 protocol freeze
- **The 3.0 extensions are defined, not yet offered.** `docs/control-messages.md` and `docs/native-api.md` now give the wire formats of HDR10+, HDR Vivid, Dolby Vision and HLG negotiation, PCM and Dolby Digital audio, 7.1.4 surround, error-correction reports, the bandwidth test, USB forwarding, text input, keyboard layouts, the device-drawn cursor, image clipboard and shared folders, so client work can start. The host offers none of them yet: `/serverinfo` and `DESCRIBE` stay byte for byte what stock Moonlight and Nonary's Moonlight see today, and an `ANNOUNCE` that picks one anyway is refused with 400 and the attribute's name.
- A device's permissions can already carry `allow_usb` and `shared_folders` grants (`read` or `write` per folder id); the console saves them only in that shape. They take effect when their features ship.
