# Shared virtual display
- **A VRR device that joins a fixed-rate device on a shared virtual display raises it reliably.** When the fixed-rate device was first, the VRR device could be refused with "shared virtual display already uses a different mode", because the host set the faster refresh a few milliseconds before Windows listed it. The host now waits until Windows lists the refresh (at most 2 seconds) and then sets it; a device turning between portrait and landscape waits the same way.
