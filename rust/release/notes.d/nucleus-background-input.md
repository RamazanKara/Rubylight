# Nucleus Co-op background streams
- **Your controller reaches the background game again.** A background stream started soon after another one now unplugs the earlier session's virtual controllers first, so the game reads your controller instead of a leftover one. When one of the PC's own controllers sits ahead of yours, the stream says so.
- **The PC's keyboard and mouse stay out of a background game.** Its window no longer gets keys, clicks, the wheel or cursor positions from the PC, even when the game comes to the front. A game that reads raw input can still see the PC's mouse while it is in front.
- **Background games stay off your monitors.** Unreal Engine games start in a window, so they stay where Rubylight parks them instead of going fullscreen on the PC's monitor. A game that keeps coming back to a monitor, or minimises itself when it loses the focus, is put back for the whole stream, not just the first few seconds.
