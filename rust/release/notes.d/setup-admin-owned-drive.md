# Setup on an administrator-owned system drive
- **Setup installs when the PC's administrator owns `C:\`.** Since 2.2.2, a system drive owned by an account in the Administrators group (after taking ownership in Explorer or a tweak) stopped setup with "C:\ must be owned by Administrators, SYSTEM or TrustedInstaller". Setup now accepts such an owner for the system drive's root, whose owner could already change Program Files. Every other folder above the installation keeps the strict rule, and the installation folder itself is still locked down to Administrators and SYSTEM. When setup refuses an owner, the message now names it ([#61](https://github.com/RamazanKara/Rubylight/issues/61)).
