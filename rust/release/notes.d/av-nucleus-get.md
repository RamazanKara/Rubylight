# Nucleus Co-op folder
- **Rubylight no longer downloads Nucleus Co-op.** The game page's Play together panel and Help link to the Nucleus Co-op 2.4.2 release instead: unpack it into a folder under C:\Program Files and choose that folder there. Rubylight checks the folder before it keeps it and says why when it refuses one: no NucleusCoop.exe, another release, a folder that anyone but administrators may change, or files Windows still marks as downloaded (unblock the zip before unpacking it). A Nucleus Co-op an earlier version downloaded keeps working. A folder chosen earlier that holds another release falls back to that copy, and the panels say so.
