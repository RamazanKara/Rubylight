## en
- Keyboard follows text fields (Experimental): on a Rubylight PC, the keyboard opens when a text field in the stream gets the focus, fitting the field (digits for numbers, no suggestions for passwords), and closes after. Off in Settings. Desktop does the same where the system has an on-screen keyboard.
- Nightjar tells a Rubylight PC its keyboard layout, so games that read raw keys get the keys on your keyboard, German included.

## de
- Tastatur folgt Textfeldern (experimentell): Auf einem Rubylight-PC öffnet sich die Tastatur, wenn ein Textfeld im Stream den Fokus bekommt, passend zum Feld (Ziffern für Zahlen, keine Vorschläge für Passwörter), und schließt sich danach. Abschaltbar in den Einstellungen. Desktop macht es genauso, wo das System eine Bildschirmtastatur hat.
- Nightjar teilt einem Rubylight-PC sein Tastaturlayout mit, damit Spiele, die rohe Tasten lesen, die Tasten deiner Tastatur bekommen, auch einer deutschen.
