# Stream and game tracking
- **The stream no longer waits for the host's game check.** Once a second the host reads the PC's process list to see whether a Steam game it launched is still running (8 ms on an idle PC, 25-43 ms when it reads the paths of newly started programs). The stream and input threads could wait behind that read while a game was loading; now they skip a look instead of waiting. Measured on the RX 7900 XT with Pioneers of Pagonia launched by the host (AV1 1080p120, 60 s from launch through the fullscreen switch): largest send gap 51 ms (the 50 ms repeat while the game drew nothing), host processing p99 1.57 ms (1.55 ms before).
- The host log now names a stream thread that stops before claiming a picture after 150 ms instead of 500 ms, with the game check as its own step.
