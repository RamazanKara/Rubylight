# Child sessions removed
- **Child sessions are gone; Nucleus Co-op is the background mode.** Windows signs a child session in only with a Windows password, and a Microsoft account that uses only Windows Hello has none, so Rubylight would have to ask for one. It doesn't, and it doesn't ask you to turn Windows Hello-only sign-in off. On a PC where a development build set child sessions up, the host puts Remote Desktop, its firewall rules, the session frame rate and child sessions back as they were at its first start, and deletes the password that build had saved (encrypted for your Windows account, never logged or sent anywhere). If that restore fails, Maintenance says why and offers Restore again, and Remote Desktop is turned off. Uninstalling does the same. A saved `background_mode` of `auto`, `child_session` or `virtual_display` becomes `nucleus`, and the log says so once.
