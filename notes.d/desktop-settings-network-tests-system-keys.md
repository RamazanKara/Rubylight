## desktop
- Network tests (the speed test and the PyroWave frame pace calibration) are now in Settings → Streaming as well as in each PC's own settings. With several paired PCs you choose the PC there.
- New setting "System keys only in full screen" (Settings → Controls → Mouse and keyboard): with "Send system keys" on, Alt+Tab, the Windows key and similar stay with your computer while the stream is in a window.
