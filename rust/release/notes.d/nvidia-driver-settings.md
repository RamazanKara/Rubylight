# NVIDIA driver settings
- **NVIDIA driver settings from the console and Nightjar.** On a host that streams with an NVIDIA GPU, the graphics settings panel (Nightjar's stream menu and the game page in the console) now controls NVIDIA's Low Latency Mode, Max frame rate, Vertical sync, Power management mode, Texture filtering quality, Anisotropic filtering and Smooth Motion (driver 571.86 or newer). As with Radeon settings, the host records the PC's own values first and puts them back when the session ends, after a crash too. A value the panel can't put back exactly, such as one set in NVIDIA Profile Inspector, is shown and left alone.
- **Game presets work on NVIDIA.** Competitive sets Low Latency Mode to Ultra, Smoothness caps the frame rate at the stream's, and Quality sets 16x anisotropic filtering with high-quality texture filtering. On Radeon the presets set what they did before.
