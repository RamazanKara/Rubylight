## en
- On the Xiaomi FX Mini LED Fire TV (AFTNE4E43F), Android's low-latency decoding now starts off once, because the picture could break into coloured blocks with it on. Decoding takes longer with it off. If you turn it back on, Nightjar keeps that choice, asks the PC for a single reference frame and asks for a fresh keyframe when none came for 10 seconds. Other devices don't change.
- Problem reports name the device, put a UTC time on each line and list the last 8 streams, and slow decoder input makes one summary line per 10 seconds instead of filling the log.
