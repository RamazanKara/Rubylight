## en
- Show frames at the PC's frame times is now called Real VRR: each frame is shown when the game drew it, so a screen with adaptive refresh (ARR) refreshes in step with the game.
- Real VRR no longer holds every frame back on a busy Wi-Fi link: on a screen with ARR, a frame much later than the others is shown as soon as it is ready.

## desktop
- Show frames at the PC's frame times is now called Real VRR. With Variable refresh rate on, each picture is shown at the time the game drew it, so a G-Sync or FreeSync display refreshes in step with the game, a little over 1 ms behind on a clean link.
- Real VRR no longer holds every picture back on a busy Wi-Fi link: a picture more than 2 ms later than the typical one is shown as soon as it is ready. Over Wi-Fi it now adds 2.6 to 4.2 ms instead of 8 to 10 ms.
