# Virtual mouse and touchpad
- **A mouse games read like a real one.** With the optional USB audio and haptics driver installed, the PC's mouse is a virtual USB mouse polled every millisecond, with fine wheel steps and horizontal scroll, instead of Windows input injection, which some games and anti-cheat ignore. **All settings › Sound & controls › Mouse input method** (`mouse_mode`): Automatic (the default, the virtual mouse when the driver is there), Virtual mouse or Injection, also per game and per device. Without the driver, mouse input is injected as before, and the stream says why when Virtual mouse was chosen.
- **Touchpad gestures from devices.** A tablet's keyboard-cover touchpad or a laptop's touchpad in Nightjar reaches Windows as a precision touchpad, so two-finger scroll, three- and four-finger gestures and Windows' touchpad settings work (`native_touchpad`, on by default, with the same driver).
- `input_latency_probe` shows whether a game sees the mouse as injected and how long a move takes to reach it ([Virtual mouse and touchpad](../docs/virtual-mouse.md)).
