# Second screen
- **A device's second screen streams under one pairing (#75).** Nightjar's Dual screen mode streams a second display to the same device next to its first stream: the host keeps it as a stream of its own, so it neither replaces the first screen's stream nor shares its display, and puts the two virtual displays back where the user left them the last time they streamed together. Both screens follow the device's permissions and settings, each keeps the resolution and scale picked on it, each screen's bitrate changes, clipboard and statistics reach its own stream, and unpairing or turning the device off ends both. Moonlight and a launch without Dual screen mode behave as before.
