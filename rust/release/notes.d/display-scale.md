# Display scale
- **A device can set the Windows scale of its virtual display.** A device that asks for it (Nightjar's **PC display scaling**, on Android and desktop) gets that text and interface size on its virtual display, ahead of the device, app and host **Virtual display scale**; the resolution stays as asked. A scale too large for the display's resolution is lowered to the largest Windows offers there, with a warning. Stock Moonlight is unchanged.
