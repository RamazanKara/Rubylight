- **HDR dynamic metadata.** HDR streams carry per-frame HDR10+ (SMPTE ST 2094-40, profile A) brightness statistics in HEVC and AV1, so displays that tone-map with HDR10+ can follow each scene instead of one static peak. HEVC streams also carry HDR Vivid (CUVA 005.1) statistics. Each frame carries the statistics of the frame before, so scene cuts show up one frame later; the first frames, before any measurement, carry values from the stream's static HDR10 levels. They are measured on the GPU behind the compute conversion while the frame encodes; packed 4:4:4, the D3D11 conversion and PyroWave carry none, and the web UI says so for the first two. FFmpeg reads both back from spliced HEVC and AV1 frames, and hdr10plus_tool accepts every frame as profile A. Moonlight drops them from HEVC before the decoder; Nightjar keeps them. In AV1 they reach any client whose decoder reads them. Clients without HDR10+ ignore them. `hdr_dynamic_metadata` (on by default) turns it off.
