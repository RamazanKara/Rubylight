# Shared virtual display
- **A VRR device and a fixed-rate device share one virtual display.** With **One shared by all devices**, a device that asked for VRR made the display 1000 Hz, and a second device at the same size without VRR was refused with "shared virtual display already uses a different mode" (and the other way round). Now a display that refreshes at least as often as a device asks serves it, and a device that asks for more raises the shared display's refresh in place, so the VRR device keeps VRR. A device at another size is still refused, and the message names both sizes.
