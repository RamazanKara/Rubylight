# Frame generation
- **Neural Rendering is now frame generation.** A game's switch puts a third-party frame generation mod into games that ship DLSS frame generation: turn on DLSS frame generation in the game, and it takes its place. It runs on Radeon RX 5000 and newer, the Radeon 780M among them, and on GeForce GTX 16, RTX 20 and newer, downloads about 14 MB, and refuses games with a known anti-cheat. Leave it off for online games.
- A game that already has OptiScaler gets only the frame generation add-on, and its settings are put back exactly when it is turned off.
- The earlier neural upscaling is no longer offered. A game that still has it shows it on its page with Remove, and turning frame generation on removes it first; its 1 GB download is deleted.
- Paired Nightjar devices can turn a game's frame generation on and off when the device has Host control.
