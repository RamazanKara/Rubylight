- **Rumble stops reach the client with rumble off.** A client that turns rumble off mid-buzz still gets the game's stop for the main and trigger motors, once, so they don't stay on; with rumble off and nothing running, no rumble packets go out. Steam Controller rumble the host synthesizes (Experimental: no shipped driver produces it yet) stops when the controller is removed, when the client turns haptics off and when the session ends, and its pending pulses are dropped.
