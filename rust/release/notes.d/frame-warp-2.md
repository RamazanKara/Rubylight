# Frame Warp 2
- **Frame Warp 2.** The host fits a game's camera response as each move comes in, alongside the four-second fit, and sends the model as soon as it explains 80% of the motion; a saved game is confirmed by the first turn. It learns the pad's gyro as a third camera input, and tags every frame with how sure it is that the camera moves the picture, so a scene cut, a move the model doesn't explain or, with Desktop Duplication capture, a pointer on screen stops the warp instead of pushing a menu the wrong way. `frame_warp.json` keeps the gyro's gain and moves to a new format by itself; a damaged file is set aside as `frame_warp.json.corrupt` and the game is learned afresh. Frame Warp 2 replaces the first Frame Warp and needs the current Nightjar and host together: an older Nightjar streams normally without Frame Warp, and a current Nightjar tells the player when the host is too old. The `frame_warp` setting keeps its value.
