# NVENC at full clocks
- Experimental: **NVIDIA encodes at full GPU clocks.** NVIDIA's power management lowers the clocks of a GPU that a capped or light game barely loads, and NVENC slows down with them. A user's RTX 5070 took about 6 ms per 4K60 frame with the game capped at 60 fps. The host now sets NVIDIA's power management for itself to "Prefer maximum performance", in a driver profile named Rubylight that covers only the host, as Sunshine-based hosts do. An idle host uses no GPU, so the clocks rise only while it streams. Turn off Full GPU clocks while streaming (`nvenc_latency_over_power`) in the NVIDIA NVENC settings to keep the driver's own power management.
