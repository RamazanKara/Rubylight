# Settings home
- **Settings shows what most people change.** The Settings page now holds ten settings in plain words: this PC's name and pairing, the stream preset, the virtual display, whether your monitors turn off while streaming, sound, microphone and controllers, closing the game when the last device leaves, and automatic updates. Wake and sleep status, updates, signed-in browsers and the password moved here from Help.
- **Search finds every setting.** The search box on Settings covers every key and opens it in All settings, scrolled to the setting.
- **All settings shows everything.** Each topic lists all its settings; only expert groups (capture troubleshooting, AMD AMF, RTSS, ports, console sessions and debug switches) start folded, and a group you changed opens by itself.
- QR pairing and bitrate lowering on a bad link are always on; their switches sit under Debug switches for troubleshooting.
