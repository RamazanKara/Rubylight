## en
- Android and desktop share one set of stream hotkeys, the ones Moonlight uses (Ctrl+Alt+Shift+Tab opens the stream menu, Q disconnects, Z releases input, S shows the overlay), and each can be changed or turned off in Settings → Controls → Stream hotkeys.
- On Android the stream menu moved from Ctrl+Alt+Shift+M to Tab and the local cursor from C to P; the old keys still work in this release and say once where they moved.
- To change one, press the new keys; a key pressed alone gets Ctrl+Alt+Shift. Combinations used for typing (Shift+A, AltGr letters, Ctrl+C) and the ones Windows keeps (Alt+Tab) are refused, and desktop always keeps a hotkey for Stream controls or Disconnect.
