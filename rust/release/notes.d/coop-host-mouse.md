# Co-op host mouse
- **The PC's mouse stays free once you click away from a game that refused Nucleus Co-op's input hooks.** Nucleus Co-op told such a game every second that it was the active window, so a game like Assassin's Creed IV: Black Flag Resynced kept pulling the cursor towards its window beside the desktop. It no longer gets those messages. While the game is really in front it may still hold the mouse, since it reads the stream's controller only then: one click elsewhere on the PC, or Alt+Tab, frees the mouse and stops the controller until you click the game's taskbar icon. A game that pauses when it is not in front now stops its picture on the stream too.
