- **Background streaming in a Windows child session (Experimental).** On Windows Pro and higher a device can play on a desktop of its own, a Windows child session of your account with its own input focus and apps, while you keep using the PC. Set **Background mode** to **Child session**, set it up under Maintenance, enter your Windows password (not the PIN; it is stored DPAPI-encrypted for your account and never logged) and start it; a second host in the child session streams it and pairs like any host. Windows shortcuts stay on your own desktop. Setup keeps Remote Desktop on this PC only (its firewall rules stay off, a block rule closes the port to the network), raises the session frame rate and records every original value; Restore and uninstalling put them back. Limits: no HDR, about 120 fps from the RDP compositor, and Windows may render it on an integrated GPU, which the host detects and says loudly. Windows Home keeps the virtual-display mode. Off by default. Ported from Annex (mattxslv/annex, MIT).
