- **Keyboard follows text fields: per-field ids (Experimental).** For a client that asks (`TextInputVersion` 2), the host's text field notice names the focused control, so Nightjar keeps its keyboard closed only for the field you closed it on, also when the focus comes back to that field. A tooltip over the field, the host's own window or an app too busy to answer no longer lowers and raises the keyboard. Stock Moonlight and older clients get the same notices as before.
