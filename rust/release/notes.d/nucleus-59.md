# Nucleus Co-op starts (#59)
- **Background streams through Nucleus Co-op start the game.** Rubylight's profile left each player's processor setting empty, which Nucleus Co-op 2.4.2 can't read, so a start failed just after the game's process came up. The profile now says "any processor", as Nucleus Co-op itself writes it.
- **A click on the profile that comes too early no longer stalls the start.** Nucleus Co-op answers a click made while it still builds its setup screen with "The profile can't be loaded" and then ignores every later click. Rubylight now closes that box and clicks the profile again until the game starts. Tested on the RX 7900 XT with Nucleus Co-op 2.4.2 running as a standard user: the game's process and window came up about 11 s after launch, and its window was captured at 1280x720.
- A start that times out now says where Nucleus Co-op stopped (its setup screen still waiting for a player's controller, or boxes closed after every click) instead of asking you to load the profile by hand.
