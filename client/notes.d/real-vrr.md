## en
- Real VRR, on by default with Variable refresh rate: each frame is shown at the time the game drew it, so a screen with adaptive refresh (ARR) refreshes in step with the game, not the network. Turn it off for the lowest latency.
- On a busy Wi-Fi link, a frame much later than the others is shown as soon as it is ready instead of holding every frame back.

## desktop
- Show frames at the PC's frame times is now called Real VRR and is on by default with Variable refresh rate, also in settings saved before: each picture is shown at the time the game drew it, so a G-Sync or FreeSync display refreshes in step with the game, a little over 1 ms behind on a clean link. Turn it off for the lowest latency.
- Real VRR no longer holds every picture back on a busy Wi-Fi link: a picture more than 2 ms later than the typical one is shown as soon as it is ready. Over Wi-Fi it now adds 2.6 to 4.2 ms instead of 8 to 10 ms.
