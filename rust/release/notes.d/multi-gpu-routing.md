# Multi-GPU routing
- **A PC with an iGPU beside a graphics card of the same make streams on the card.** With Graphics card on Automatic, a Ryzen desktop whose integrated GPU is enabled next to a Radeon or GeForce card, or a laptop with a Radeon iGPU and a Radeon card, used to render the virtual display and test its encoders on whichever GPU Windows listed first, often the iGPU, which reports fewer codecs (no AV1 on a Ryzen desktop's iGPU) and encodes slower. Rubylight now takes the GPU Windows ranks first for performance (external, then discrete, then integrated), then the one with the most video memory, and the console log names it. A display connected to an AMD or NVIDIA GPU still streams from that GPU, a PC with one GPU is unchanged, and a GPU chosen under Graphics card always wins.
