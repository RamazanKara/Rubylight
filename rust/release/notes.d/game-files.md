# Per-device game settings and managed game files
- **One game, different settings per device.** The app editor's new **Per device** panel gives a game its own stream preset, frame limit, Radeon preset and game files on one paired device, such as 60 fps on the TV and 120 on a handheld. These win over the game's own settings and the device's. Settings for a device that is no longer paired are kept and not used.
- **Managed game files.** A game's own `.ini` keys, such as OptiScaler's `FramerateLimit`, can now follow the stream. List them in the app editor's **Managed game files** panel with a fixed value or `{stream_fps}` (`{stream_fps-1}` for one below the stream's frame rate). The host sets them when a stream starts the game and puts them back when the session ends, the device is unpaired or the host shuts down, or at the next start after a crash. Every other byte of the file stays as it was. A value you changed yourself in the meantime is kept.
  The host only writes an existing `.ini` file inside the game's folders. It warns in the log when a frame limit there differs from the RTSS limit.
