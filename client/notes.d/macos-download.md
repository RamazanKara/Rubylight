## desktop
- Nightjar for macOS is now a release download: `nightjar-desktop-<version>-macos-arm64.zip` for Apple Silicon and `…-macos-x86_64.zip` for Intel Macs, macOS 13 or later. The app is not notarized by Apple, so macOS asks once on first start; the [macOS guide](https://github.com/RamazanKara/nightjar/blob/main/protocol/desktop/README.md#install) shows how to allow it.
