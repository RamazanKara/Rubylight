# Slice delivery
- **4K streams arrive sooner.** H.264 and HEVC streams with 4K-size pictures (3840x2160, 4096x2160, 5120x1440) now send each frame slice by slice while the encoder finishes the rest, with no client change; Moonlight and Nightjar reassemble the frames as before. Smaller pictures still go out whole, because there it measured no gain. `video_slice_delivery = off` turns it off, and `2` or `4` turn it on for every size. Measured on the RX 7900 XT at 4K60 HEVC: the picture arrived 1.2 to 1.3 ms sooner on loopback and 0.5 to 1.0 ms sooner paced as for a Wi-Fi client (October: 1.4 ms over Wi-Fi 6E to Nightjar on a laptop). On these streams Moonlight's overlay shows about 2 ms more host processing time, although the picture arrives sooner.
