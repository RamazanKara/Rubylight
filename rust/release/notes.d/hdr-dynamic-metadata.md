- **HDR dynamic metadata.** HDR streams carry per-frame HDR10+ (SMPTE ST 2094-40) brightness statistics in HEVC and AV1, so displays that tone-map with HDR10+ can follow each scene instead of one static peak. HEVC streams also carry HDR Vivid (CUVA 005.1) statistics. The statistics target the client's reported peak brightness, else the host display's, else 1000 nits, and follow scene cuts at once. They are measured on the GPU behind the compute conversion while the frame encodes; packed 4:4:4, the D3D11 conversion and PyroWave carry none. FFmpeg reads both back from spliced HEVC and AV1 frames. Clients without HDR10+ ignore them. `hdr_dynamic_metadata` (on by default) turns it off. The metadata writers are ported in part from Foundation Sunshine (GPL-3.0).
