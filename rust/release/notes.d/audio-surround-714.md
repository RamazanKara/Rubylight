# 7.1.4 surround
- Experimental: **7.1.4 surround.** A client that asks for 12 channels gets 7.1.4 Opus (normal and high quality, RFC 7845 channel mapping). The host captures the four height channels from a playback device that has them; on any other device they stay silent, with no upmix. On by default (Settings, Audio, "7.1.4 surround"); stock Moonlight clients stream as before.
