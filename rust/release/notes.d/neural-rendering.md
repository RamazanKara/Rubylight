# Neural Rendering
- Experimental: **Neural Rendering, a switch on each game's page.** It installs a third-party neural upscaling mod into the game's folder, for games with DLSS, FSR or XeSS, and takes it out again. The first time, a notice says what it is and that it is at your own risk; Cancel is the default. This PC downloads the mod (about 1 GB; the switch goes on only while no stream runs) from its authors' GitHub release and checks it against the release's published checksums; Rubylight ships none of it. Games with anti-cheat or another upscaler mod are refused with the reason, the mod goes only beside the game's own program, never a launcher's, other programs' files are never overwritten, nothing is changed through a link inside the game's folder (a game folder moved elsewhere and linked back is followed, for the signed-in user only), and turning it off, deleting the game or uninstalling it from its launcher removes only what Rubylight put there (a game on a drive that is not connected is cleaned up once the drive is back). Each launch checks the files and applies a newer release, which a daily check outside streams fetches. The Radeon graphics Rubylight streams with need RDNA 3 or RDNA 4 with 12 or more compute units, and AMD Software 26.9.1 or newer; anywhere else the switch is off and says why. Measured on the RX 7900 XT PC: the 1.0 GB release downloaded and checked in 88 s, and removal left the test folder as it was, also after an update cut short by a file held open.
