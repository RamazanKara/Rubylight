# Playnite games
- **No false "game not detected" warning after a Playnite game.** With per-device settings files, every stream of a game started through Playnite ended with the warning that no process of the game was seen, although the files were swapped and saved correctly. Rubylight now finds the game's programs in its folder.
- **Wait after a game closes** is a new setting under Games & automation → Playnite: how long a Playnite game must stay closed before its stream ends. It stays at 15 seconds unless you change it, because a game that starts through a launcher or restarts itself is briefly reported closed. Until now the wait was fixed, and the exit timeout, which is how long a game gets to close when Rubylight ends it, did not shorten it; its description now says so.
