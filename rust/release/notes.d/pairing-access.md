# Pairing access
- **A second device can play.** When you pair a device from the console, you choose what it can do: Play games (the default), Watch only or Everything. Before, every device after the first could only watch until you found its permissions. Devices already paired keep theirs, the first device still gets everything, and stock Moonlight pairing works as before.
- **The device page says what a device can do in words.** Play games, Watch only, Everything or Custom; Custom opens the single permissions.
- **The QR code and the Artemis one-time PIN no longer cancel each other.** Each works once for three minutes, and a second console tab shows the same QR code instead of replacing it.
