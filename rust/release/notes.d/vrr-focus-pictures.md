# VRR pacing
- **Another window's animation no longer makes a focused VRR game repeat and skip frames.** A 60 Hz game streamed at 60 fps on a 240 Hz VRR desktop repeated and skipped frames while another window on the captured display animated: Windows Graphics Capture delivered a picture every refresh, and each counted as a new one. On Windows 11 24H2 and newer the host now reads which part of the screen each capture changed: while the foreground window animates, another window's update joins its latest picture instead of starting a new one, and so does a pointer move. A game alone on the display is paced as before. On an RX 7900 XT (60 Hz game, 60 fps HEVC stream, another window at 240 fps beside it), repeated game frames fell from 159 to 294 per one-minute run to 0 to 20, and the host's capture age p99 from 6.2 to 16.5 ms to 0.4 to 6.1 ms.
