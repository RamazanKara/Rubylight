# Security and privacy
- **No sign-ins to other computers from the file picker or covers.** The console's file picker and the app covers no longer open network paths (`\\server\share`) or device paths (`\\.\`, `\\?\`, `NUL`, `COM1`), which would make the PC sign in to the named computer with its own account. The file picker says why it refused one. An app whose cover is on a network path shows the default cover, and the console names it with a warning until you copy the image to the PC and choose it again. Covers on a drive letter, mapped to a share or not, work as before.
- **Pairing limits hold across an IPv6 network prefix.** Moonlight pairing requests are now counted per IPv4 address or per IPv6 /64, as sign-ins and WebRTC pairing already were, so a device can't get around the limit of two waiting requests by rotating its privacy address. The tray's pairing notice shows at most once every 30 seconds per device; the console still lists every request.
- **The PyroWave bandwidth probe waits its turn.** `/pyrowave-bandwidth-probe` (32 MiB) is now refused while a stream runs or starts, and each device may fetch it once every 15 seconds and twice a minute, like the other bandwidth probe.
- **First-run setup only from the PC itself.** The console's first password can no longer be set through a reverse proxy or tunnel on the PC (nginx, cloudflared, `tailscale serve`): requests carrying `Forwarded` or `X-Forwarded-*` headers, or a `Host` or `Origin` other than the PC's, count as coming from elsewhere. If you reach the console only through such a proxy, set the first sign-in on the PC with `butterpollo.exe --creds NAME PASSWORD` from an administrator PowerShell, then sign in through the proxy as usual.
- **Tighter console sessions and API tokens.** Renewing a console session from its cookie now needs the page's CSRF token, which the console sends. API tokens can no longer be granted the password change or the file picker (`/api/password`, `/api/browse`), and existing tokens that held them lose those two routes; everything else they were granted keeps working.
