# Background mode follow-ups (#59)
- **Background games play only on the client.** In background mode and with game-only audio, the game's sound played on the PC's speakers as well as on the client. The game now plays on a virtual playback device nobody hears (Steam Streaming Speakers, or the virtual sink set in Audio settings) while the client still gets it, and goes back to its own device when the stream ends. If the game quit or the host stopped mid-stream, that happens the next time the game runs. Nothing else on the PC changes device. Without a virtual playback device the stream says the game also plays on the PC.
- **Games that refuse Nucleus Co-op's input hooks start again.** Without hooks (Assassin's Creed IV Black Flag Resynced), Nucleus Co-op stayed on its setup screen because it no longer listed the controller. It lists it again, so Rubylight's profile can start the game.
