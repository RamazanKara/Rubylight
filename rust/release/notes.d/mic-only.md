# Microphone only
- **Microphone only sessions** for Nightjar: a device can be the PC's microphone with no stream, through the normal microphone path (Steam Streaming Microphone, level clamp). It needs only Launch apps, not Input-only sessions; the session takes no input, starts no app and leaves the PC's sound on the PC. Listed as `session.mic_only` in the native API (Spidey2111, #56).
