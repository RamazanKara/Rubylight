# Settings reference

[Documentation](index.md)

Open **Settings** for **Stream**, **Controls**, **Overlay & audio**, **App** and **Advanced**. Search matches setting titles, descriptions and categories, including Advanced settings. Unsupported options remain hidden or disabled.

The tables between the markers below are generated by [generate-settings.py](../scripts/generate-settings.py) from [preferences.xml](../app/src/main/res/xml/preferences.xml), the English resource strings/arrays, and the Java defaults and preset writes. Regenerate them after changing preferences; do not edit the generated rows by hand. The generator checks that XML defaults agree with the runtime defaults. [Documentation checks](building.md#documentation-checks) detect stale output.

Defaults describe a fresh installation before a preset or PC override. A fresh installation matches **Custom**, not Balanced: it starts at 720p, 60 FPS, 10 Mbps and Lowest latency pacing. Changes to global stream configuration apply to the next stream. The stream menu exposes the controls that can change during a session.

These tables include every preference, including actions. On/Off choices have no units; action rows have no stored default. Device capability checks can hide or disable a row.

## Presets

Presets change only the following global values. Other settings, including resolution, HDR and sharpening, stay as selected. Saved PC profiles take priority. The selected chip says Custom when values do not match a preset.

| Setting | Balanced | Low latency | Best quality | Battery saver |
| --- | --- | --- | --- | --- |
| Video codec | Automatic (recommended) | Keep selected codec | Automatic (recommended) | Automatic (recommended) |
| Video bitrate | 15 Mbps | 15 Mbps | 40 Mbps | 8 Mbps |
| Video frame rate | Screen maximum (rounded, 1–1000 FPS) | Screen maximum (rounded, 1–1000 FPS) | Screen maximum (rounded, 1–1000 FPS) | 30 FPS |
| Variable refresh (VRR) | Off | On | Off | Off |
| Client-side upscaling | Off | SGSR 1 (Snapdragon Game Super Resolution) | FSR 1.0 | Bilinear |
| Frame pacing | Balanced | Lowest latency | Balanced | Balanced with FPS limit |
| Keep only the newest frame | Off | Off | Off | Off |
| Allow lower refresh rate | Off | Off | Off | On |
| Decoder performance hints | On | On | On | Off |
| Phone performance hints | Off | Off | Off | Off |

Choose Balanced for mixed play, Low latency for fast response, Best quality for a stable high-bandwidth connection, or Battery saver for a 30 FPS target with reduced decoder performance hints.

## Per-PC stream profiles

Long-press a PC and choose **This PC → Stream settings**. **Use global settings** is on until a profile is saved. Turn it off, edit the draft and choose **Save**. To remove the override, turn it on and save again. Leaving without saving discards the draft.

These controls are created in [HostStreamSettings.java](../app/src/main/java/com/limelight/preferences/HostStreamSettings.java), with validation in [HostStreamProfile.java](../app/src/main/java/com/limelight/preferences/HostStreamProfile.java).

| Setting | Initial value and units | When to change |
| --- | --- | --- |
| Use global settings | On; no PC override | Turn off when this PC needs a different stream setup. |
| Video resolution | Current effective size; width and height each 64–16384 pixels | Match a host display or choose a lower decode workload. **Use this screen** fills in the device's landscape dimensions. |
| Video frame rate | Current effective refresh; 1–1000 Hz, up to two decimal places | Request fractional rates such as 59.94 or 119.88 Hz. **Use this screen** fills in maximum display refresh; VRR also uses the panel maximum. |
| Video bitrate | Current effective bitrate; 0.5–2000 Mbps, up to three decimal places | Set this PC's bandwidth budget. Startup can exceed the global slider's 500 Mbps ceiling; runtime changes remain capped at 500 Mbps. |
| Video codec | Current effective codec; Automatic, Prefer AV1, Prefer HEVC, H.264, PyroWave | Compare codecs on this PC and device. |
| Upscaling / sharpening | Current effective mode and 0–100% sharpness | Choose a scaler for this PC's lower-resolution SDR stream. |
| HDR / Variable refresh (VRR) | Current effective On/Off values | Enable for a compatible host and screen. |
| Host virtual display | Current effective On/Off value | Request a separate host display matching this stream. |
| Host render scale | Current effective scale; 50–200% | Change host render pixels relative to stream pixels. Used with the virtual-display request. |
| Prefer YUV 4:4:4 / Force full-range video | Current effective On/Off values | Request supported chroma/range behavior for this PC. |
| Save | Action | Store the complete draft or remove the profile when using global settings. Takes effect next stream. |

A new profile starts from the current effective settings, not a second set of factory defaults. Host device/app policy may override a request. Older profiles without VRR or upscaling fields inherit those fields globally.

## Settings available during a stream

| Control | Default / persistence | Use |
| --- | --- | --- |
| Touch mode | Trackpad initially; saved globally | Switch Trackpad, Direct mouse or Multi-touch immediately. |
| Show on-screen controls / Edit controller layout | Hidden initially; saved control preference/layout | Show the virtual gamepad, move/resize it and save. |
| Overlay visibility / mode | Off / Compact initially; saved globally | Show, hide, switch Compact/Advanced or copy detailed stats. |
| Set bitrate | Starts from the effective stream configuration; session adjustment | Request 0.5–500 Mbps, subject to host limits. A manual selection disables automatic bitrate. |
| Automatic bitrate | Off initially; saved per PC, separately for PyroWave and conventional codecs | Lower bitrate under congestion and recover gradually within the selected/host cap. Requires a supporting Rubylight host. |
| Keyboard, clipboard and host actions | Actions, not factory preferences | Open the keyboard, transfer text explicitly, view host status, reconnect, disconnect or request app exit. Host permissions apply. |

## Reset scope

**Settings → App → Reset all settings** restores the global preferences and touch-mode flags. It keeps paired PCs, per-PC stream profiles, controller button mappings, the on-screen layout and the selected app language. Reset a PC profile in its own screen, a controller in **Controller buttons**, and the layout with **Reset controls layout**.
