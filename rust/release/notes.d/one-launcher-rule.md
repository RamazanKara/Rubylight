# One rule for every launcher
- **Every installed game, from every launcher.** Steam and Playnite now add every installed game by default, as Epic Games, Battle.net, Xbox, EA, Ubisoft and GOG already did. Recently played only is still there under Steam options (Settings › Library); a setting you saved stays as it is.
- **Not installed.** A game whose launcher no longer has it installed shows "Not installed" in Library, with Remove beside it. Removing it keeps every sync from adding it back.
- **No Steam games twice with Playnite.** While Playnite keeps the library in step, it adds the Steam games too, so the Steam sync stands aside like the other launchers'.
- **Your own "Playnite (Fullscreen)" app stays.** Turning off the Playnite fullscreen entry removes only the one the host made, not an app you made with that name.
