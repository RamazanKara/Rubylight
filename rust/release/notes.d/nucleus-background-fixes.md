# Background streams with Nucleus Co-op (#56, #59)
- **One stuck file no longer blocks every background stream.** After a background stream, a file in your own copy of Nucleus Co-op (a game's profile or Rubylight's handler) could end up one Windows no longer let your account change, and from then on every background stream of any game failed with "Access is denied". Rubylight now checks those files before each start, and when one is stuck it sets that copy aside and makes a fresh one. What it can't remove of the old copy is tried again at the next start.
- **Games that refuse Nucleus Co-op's input hooks start without them.** Rubylight's own one-player handler has Nucleus Co-op inject ProtoInput into the game, which keeps it from the PC's keyboard and mouse. Some games refuse that (Assassin's Creed IV Black Flag Resynced does), and Nucleus Co-op then shows "ProtoInput failed to runtime inject" and ends the game. The stream now ends saying so, and from the next start Rubylight's handler for that game injects nothing: Nucleus Co-op still tells the game it has focus, but a keyboard, mouse or pad on the PC can reach it too.
