- **Dolby Vision on AV1.** AV1 HDR streams now offer Dolby Vision profile 10.1 to clients that ask for it, beside profile 8.1 and 8.4 on HEVC: each frame carries the same Dolby Vision RPU as on HEVC, in an AV1 metadata OBU before the picture, over the stream's HDR10 base layer, so devices without Dolby Vision and stock Moonlight get the AV1 HDR10 stream they always did. `hdr_dolby_vision` turns it off with the rest of Dolby Vision.
