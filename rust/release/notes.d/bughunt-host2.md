# Bug hunt: host fixes 2
- After a crash, display recovery keeps the frame limiter, audio, display activation and layout restores that failed and tries them again at the next start, instead of forgetting them.
- Resetting display persistence in the web UI is refused while a stream is starting, running or ending, or an app still runs, and says so.
- After a crash on a host whose only display was the virtual one, display recovery no longer fails at every start and slows every stream end.
- A Steam Streaming Microphone install that fails is tried again on a later connection (at most every 2 minutes) instead of never again until the host restarts.
- Ending a stream while its microphone device is still being installed or opened no longer holds up other clients' microphones.
- 7.1.4 audio played on 7.1, 5.1 or stereo speakers keeps the height channels, mixed into the speakers below them, instead of dropping them.
- Turning USB forwarding off in the web UI detaches every forwarded device right away, not only when its stream ends.
- Image clipboard requests take turns, so several at once can no longer add up to gigabytes of memory; a device's second one while its first still runs gets 429.
- With clipboard sync, a device that copies faster than the PC's clipboard takes the copies no longer piles them up in memory: only its newest copy waits.
- A client whose virtual display fell back to WGC capture after two failed frame-ring starts gets the frame ring again once its display is recreated or the driver restarts, instead of only after a host restart.
- A virtual controller that will not unplug when its stream ends is logged, and its slot is kept and freed once it does unplug, so the next client's controller is not plugged over it.
- Two clients streaming with Steam Deck controllers at once get Decks with different USB serials, so Windows and Steam Input no longer mix them up.
- When the gamepad driver refuses to plug a controller, the warning and log give the driver's error instead of "no free virtual controller slots".
- A Nintendo controller on a gamepad driver without the Switch Pro profile plays as a DualSense, which keeps its gyro, instead of an Xbox pad, and the session warns that setup should be run again to update the driver.
- A touch whose reported contact size is out of range, such as infinite, no longer crashes or misplaces touch input; the contact area stays inside the display.
